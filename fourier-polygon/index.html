Fourier polygons

An N-gon written in discrete Fourier coordinates: vj = ωj + Σk=2N−1 zk ωjk, with ω = e2πi/N. Fixing the first mode at 1 removes translation, rotation and scale, so each complex coefficient zk is pure shape, and z = 0 is the regular polygon. Drag a vertex or a coefficient; hover a dial to see that mode alone.
